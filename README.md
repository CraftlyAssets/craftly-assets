# Craftly Assets — portfolio site

Static single-page site for **Craftly Assets**, a studio producing commercial-use
digital design assets: SVG cut files, seamless patterns, clipart, colouring pages,
digital papers and teaching materials.

## Structure

```
index.html          the page
styles.css          styles, no external dependencies
assets/samples/     sample artwork (SVG)
```

## Local preview

Open `index.html` directly, or serve the folder:

```bash
python -m http.server 8000
```

## Artwork

All artwork under `assets/samples/` is original work made for Craftly Assets.
